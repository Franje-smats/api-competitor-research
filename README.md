# API Competitor Research

Public-source backfill covering 1 June–26 October 2026. Deploy index.html as a static site on Vercel (Other preset; no build command).

Includes month filters, pagination, article metadata, newsletter activity, mentions and public social examples. CSV export includes all matching results across all pages. Metadata-only entries are not full-article analyses. Full article bodies are not stored.

Coverage is bounded by the listed public archives; social and mention coverage is partial. Counts are not total publishing volume or share of voice. Undated and conflicting-date records are excluded from the verified monthly timeline. Domain coverage focuses on Research; realestate.com.au focuses on Insights. Rolling URLs count once; historical versions are not reconstructed. Automatic monitoring is not enabled.

Data is embedded in index.html. research-data.json retains the records, coverage counts and crawl history for audit. Commit changes to main to trigger Vercel Git deployments.
